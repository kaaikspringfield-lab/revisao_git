Atalhos principais do VS Code

Dicas rápidas para aumentar sua produtividade no editor

Arquivos e navegação

  • Abrir arquivoCtrl + P
  • Comandos do editorCtrl + Shift + P
  • Abrir terminalCtrl + `
  • Fechar aba atualCtrl + W
  • Alternar entre abasCtrl + Tab
  • Buscar arquivo na árvoreCtrl + Shift + E

Busca e substituição

  • Buscar no arquivoCtrl + F
  • Buscar e substituirCtrl + H
  • Buscar em todos os arquivosCtrl + Shift + F
  • Selecionar próxima ocorrênciaCtrl + D
  • Selecionar todas as ocorrênciasCtrl + Shift + L

Edição

  • Comentar linhaCtrl + /
  • Copiar linhaShift + Alt + ↓
  • Mover linhaAlt + ↑ / ↓
  • Duplicar linhaShift + Alt + ↓
  • Renomear símboloF2
  • Inserir linha abaixoCtrl + Enter

Visualização

  • Mostrar/esconder sidebarCtrl + B
  • Abrir/fechar painel de buscaCtrl + J
  • Zoom +Ctrl + +
  • Zoom -Ctrl + -
  • Resetar zoomCtrl + 0
  • Abrir explorerCtrl + Shift + E

Gerenciamento de arquivos

  • Novo arquivoCtrl + N
  • Salvar arquivoCtrl + S
  • Salvar tudoCtrl + K, S
  • Abrir nova janelaCtrl + Shift + N
  • Fechar janelaCtrl + Shift + W

Atalhos úteis

  • Selecionar linha inteiraCtrl + L
  • Ir para definiçãoF12
  • Abrir/fechar terminalCtrl + `
  • Fechar painel automáticoEsc
  • DesfazerCtrl + Z
  • RefazerCtrl + Y
Dica: combine os atalhos com a paleta de comandos para ganhar muito tempo no desenvolvimento.
